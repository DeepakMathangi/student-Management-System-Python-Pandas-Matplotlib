Student Performance Management System
A lightweight, menu-driven Python application to manage student academic data end-to-end — from data entry to visual performance analysis.
✅ Add & store student records (CSV-based, no database needed)
✅ Auto-calculate percentage & semester results
✅ Flag students falling below 75% attendance
✅ Visualize class-wide performance with Matplotlib bar charts
✅ Simple, extensible menu-driven interface
Built to sharpen data handling, file I/O, and visualization skills using Python's core libraries — Pandas, Matplotlib, and CSV.
